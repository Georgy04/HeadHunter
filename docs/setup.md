# Установка и запуск

Инструкция для ноутбука, который будет сервером на игре. Пройти её нужно один раз,
желательно не в день игры.

## Что понадобится

- Ноутбук с Windows, macOS или Linux. Он будет работать сервером всю игру.
- Node.js версии 20 или новее.
- Роутер на площадке. Он раздаёт сеть, а ноутбук подключается к нему обычным
  клиентом, как и телефоны гостей. Интернет этой сети не нужен.
- Принтер — для листа бейджей. Печатать можно заранее, хоть за неделю.

## Шаг 1. Node.js

Проверьте, установлен ли он:

```bash
node -v
```

Ответ вида `v20.11.0` или больше — всё в порядке. Если команда не найдена или
версия ниже 20, скачайте LTS-версию с [nodejs.org](https://nodejs.org) и установите
с настройками по умолчанию. После установки закройте и откройте терминал заново,
иначе он не увидит новую команду.

Сервер проверяет версию сам и при старой честно откажется работать с понятным
сообщением, а не упадёт с непонятной ошибкой.

## Шаг 2. Получить проект

```bash
git clone https://github.com/Georgy04/HeadHunter.git
cd HeadHunter
```

Если git на ноутбуке ставить не хочется, скачайте архив: на странице
[репозитория](https://github.com/Georgy04/HeadHunter) кнопка «Code» → «Download ZIP»,
распакуйте в любую папку, например `C:\HeadHunter`. Путь произвольный, пробелы в нём
допустимы. Разница только в обновлениях: клон обновляется командой `git pull`, архив
придётся скачивать заново.

## Шаг 3. Первый запуск

**Windows:** откройте папку проекта и запустите `start.cmd` двойным щелчком. Рядом
лежит `start.sh` — он для macOS и Linux, на Windows не нужен и не запустится.

**macOS и Linux:**

```bash
./start.sh
```

**Любая система, если хочется вручную:**

```bash
npm install
npm start
```

Скрипты `start.cmd` и `start.sh` при первом запуске сами поставят зависимости —
это занимает полминуты и требует интернета. На игре интернет уже не нужен, поэтому
первый запуск сделайте заранее.

В консоли появится примерно такое:

```
  HeadHunter server is running
  --------------------------------------------
  players : http://192.168.0.28:3000   [Беспроводная сеть]
  admin   : http://192.168.0.28:3000/admin?token=63e3bbb1b0db0155b2e271af
  badges  : http://192.168.0.28:3000/print?token=63e3bbb1b0db0155b2e271af
  --------------------------------------------
```

Что это значит:

- **players** — адрес для гостей. Строк может быть несколько, если у ноутбука
  несколько сетевых адаптеров: в квадратных скобках указано, какому из них
  принадлежит адрес, нужен тот, что начинается с `192.168`. Когда таких адресов
  больше одного, консоль отдельной строкой говорит, какой из них попал в ссылки и
  QR, а если два адаптера сидят в одной подсети — печатает предупреждение: ноутбук
  подключён к двум разным сетям, и телефоны увидят только одну из них.
- **admin** — пульт ведущего. Ссылка содержит токен, откройте её в браузере
  ноутбука и добавьте в закладки.
- **badges** — лист бейджей для печати.
- **board** — табло на большой экран: откройте на телевизоре или проекторе, оно
  обновляется само.
- Ниже печатается QR-код с адресом для гостей — его можно показать с экрана.

Токен ведущего создаётся один раз и дальше не меняется. Он лежит в папке `data/`
вместе с состоянием игры.

**Окно консоли должно оставаться открытым.** Пока оно живёт — живёт сервер. Закрыли
окно или нажали `Ctrl+C` — игра остановилась. Состояние при этом сохраняется на
диск, так что после повторного запуска все игроки, очки и контракты на месте.

Остановить сервер можно тремя способами, любой годится: `Ctrl+C` в окне, закрыть
окно, или — если окно потерялось среди других — двойной щелчок по **`stop.cmd`** в
папке проекта. Второй раз запускать `start.cmd` не нужно: он заметит уже
работающий сервер и скажет об этом, вместо того чтобы падать с ошибкой про порт.

## Шаг 4. Разрешить порт в брандмауэре (Windows)

Без этого телефоны не откроют страницу. Нажмите «Пуск», наберите `powershell`,
запустите **от имени администратора** и выполните:

```powershell
netsh advfirewall firewall add rule name="HeadHunter" dir=in action=allow protocol=TCP localport=3000
```

Та же команда печатается в консоли при каждом запуске сервера, её можно скопировать
оттуда. Достаточно один раз на ноутбук.

## Шаг 5. Подключить ноутбук к роутеру и настроить на долгую работу

Сеть раздаёт роутер, ноутбук — его обычный клиент. От него требуется только быть в
той же сети, что телефоны гостей:

- если у ноутбука есть Ethernet-порт, подключите его к роутеру **кабелем** — это
  устойчивее Wi-Fi; гости придут по Wi-Fi и окажутся в той же сети;
- подключив кабель, **выключите на ноутбуке Wi-Fi**, если он ведёт в другую сеть.
  Ноутбук в двух сетях сразу — частая и незаметная поломка: адреса у разных
  роутеров выглядят одинаково, а телефоны достучатся только до одного из них.
  Разбор — в [network.md](network.md#ноутбук-не-должен-быть-в-двух-сетях-сразу);
- если у роутера есть **гостевая сеть**, ноутбук и гости должны быть в одной и той
  же. Гостевые сети обычно запрещают клиентам видеть друг друга, и тогда телефон не
  откроет страницу, хотя интернет у него будет;
- полезно закрепить за ноутбуком постоянный адрес в настройках роутера («DHCP
  reservation»): тогда он не изменится за все дни игры.

Игра идёт несколько дней, и сервер должен пережить это без внимания:

- ноутбук держите **подключённым к питанию**;
- отключите засыпание: Windows — «Параметры» → «Питание» → «Сон» → «Никогда»
  (важно: в спящем режиме сервер не отвечает);
- закрытая крышка обычно тоже усыпляет ноутбук — либо оставьте открытой, либо
  поменяйте действие при закрытии крышки на «Ничего не делать»;
- не выключайте Wi-Fi и не переключайте ноутбук на другую сеть.

### Если ноутбук всё-таки перезагрузился

Игра не теряется. Всё состояние лежит в `data/state.json` и записывается после
каждого действия, поэтому переживает и перезагрузку, и выдернутый шнур: пропасть
может разве что действие, случившееся в последние доли секунды перед выключением.

После включения запустите `start.cmd` снова — и продолжится всё: очки, контракты,
собранные подсказки, выданные бейджи, PIN-коды, салун и номер раунда. Токен
ведущего тот же, ссылка на пульт прежняя. Телефоны гостей переподключатся сами:
их вход хранится в браузере, заново регистрироваться никому не нужно, страницу
достаточно обновить.

Патроны при этом продолжают копиться и пока сервер лежит: время считается по
часам, а не по работе процесса. Час простоя — это час перезарядки, а не потерянный
час.

Единственное, за чем стоит проследить, — **адрес ноутбука**. После перезагрузки
роутер может выдать другой, и старый QR перестанет работать. Актуальный адрес
всегда напечатан в консоли и показан в пульте; чтобы этого не случилось вовсе,
закрепите за ноутбуком постоянный адрес в настройках роутера.

Подробнее про сеть и разбор поломок — в [network.md](network.md).

## Шаг 6. Напечатать бейджи и коды

Печатать нужно ровно два файла, оба лежат в папке `pool` внутри проекта:

| Файл | Что это | Сколько бумаги |
| --- | --- | --- |
| `pool/badges.html` | 50 бейджей: эмблема и короткий код | 6 страниц А4 по девять штук |
| `pool/codes.html` | 100 талонов с кодами за активности | 5 страниц А4 |

Откройте файл двойным щелчком — он откроется в браузере, — нажмите Ctrl+P и
распечатайте. Потом разрежьте: бейджи по рамкам, талоны по пунктиру.

Этот набор выпущен один раз и лежит в репозитории, поэтому он одинаков на любом
ноутбуке и переживает что угодно: сброс игры, переустановку, новую вечеринку через
полгода. Сервер берёт бейджи и коды из `pool/pool.json` сам — создавать их в пульте
не нужно. Код на бейдже нужен только вам, чтобы находить нужный в стопке; на
талоне написано, что он даёт: подсказку о цели и очки.

Выпускать набор заново почти никогда не нужно. Если всё-таки нужно (например,
бейджи потерялись целиком): `node scripts/make-pool.mjs --force`. Коды станут
другими, и старую печать придётся выбросить.

Осталось подготовить пульт. Откройте ссылку **admin** из консоли и в
**Настройках** впишите название игры и данные Wi-Fi роутера — они попадут на лист
бейджей, если придётся допечатывать с сервера.

Подробнее про правила и настройки темпа — в [game-rules.md](game-rules.md). Если
перед игрой была репетиция с ускоренным темпом, проверьте, что настройки вернулись к
боевым: таблица значений — в [rehearsal.md](rehearsal.md).

## Шаг 7. Впустить гостей

1. Гость подключается к Wi-Fi роутера и открывает адрес **players** — удобнее
   через QR-код из пульта.
2. Вводит настоящее имя, придумывает никнейм и PIN из четырёх цифр. PIN нужен
   только для возврата в свой кабинет с другого телефона — предупредите, что его
   стоит запомнить.
3. Приложение показывает ему эмблему и код бейджа. С этим экраном он подходит к вам.
4. Вы находите бейдж по картинке или коду, отдаёте его и в пульте, в разделе
   **«Ожидают выдачи»**, нажимаете «Выдал». Если отдали другой бейдж — исправьте код
   в поле рядом перед нажатием.

До нажатия «Выдал» человек в игре не участвует. Бейдж нужно носить на виду.

## Шаг 8. Начать игру

Когда все на месте — кнопка **«Старт»** в пульте. Контракты раздадутся по кругу, и
на телефонах появятся цели. Раньше времени игра не начнётся: ни регистрация, ни
выдача бейджей её не запускают.

## Во время игры

- Раздавайте талоны с кодами за активности — без подсказок игра стоит на месте.
  Каждый талон срабатывает один раз, поэтому отданный можно забыть.
- Опоздавшие регистрируются как все; после выдачи бейджа они встраиваются в
  цепочку контрактов автоматически.
- Кончились бейджи — кнопка «Добавить» в пульте и печать «только невыданных».
  Так же и с кодами: «Выпустить» в пульте и печать оттуда же.
- Кнопки в таблице игроков позволяют начислить очки вручную, выдать подсказку,
  сменить цель или удалить игрока.
- Нужна пауза — кнопки «Пауза» и «Продолжить». Конец раунда — «Финал».
- Играете вечер в несколько раундов? После «Финала» нажмите «Старт» ещё раз:
  начнётся новый раунд, никнеймы перетасуются между участниками, табло начнётся с
  нулей, а сквозной счёт на аукцион продолжит копиться. Подробнее — в
  [game-rules.md](game-rules.md#раунды).
- Табло можно вывести на телевизор — ссылка в пульте, в разделе «Управление игрой».
  Во время игры открывайте первую ссылку, с никнеймами. Вторая, «итоги вечера»,
  показывает настоящие имена рядом с очками: до конца игры её открывать нельзя,
  иначе гости мгновенно поймут, кто под каким никнеймом ходит.
- Для аукциона нужен сквозной счёт: он во второй ссылке табло и в колонке «всего»
  в таблице игроков.

## Если что-то не работает

| Симптом | Причина и что делать |
| --- | --- |
| Телефон не открывает страницу | Брандмауэр (шаг 4); телефон в другой сети роутера — например в гостевой; ноутбук подключён к двум сетям сразу. Разбор причин — в [network.md](network.md) |
| В консоли ошибка про версию Node | Установите Node.js 20+ (шаг 1) |
| `npm install` падает | Нет интернета. Первый запуск требует его один раз |
| Адрес из консоли не тот | Берите тот, что начинается с `192.168`; все адреса перечислены в консоли и в пульте |
| Пульт просит токен | Откройте ссылку **admin** из консоли целиком, вместе с `?token=` |
| Порт 3000 занят | Обычно сервер уже запущен в другом окне: остановите его файлом `stop.cmd`. Если порт занял кто-то другой, запустите игру на другом: `PORT=8080 npm start`, в Windows PowerShell — `$env:PORT=8080; npm start` |
| Регистрация пишет «свободных бейджей нет» | Выпустите ещё бейджей: «Добавить» в пульте |
| Игрок потерял доступ к приложению | Кнопка «Я уже регистрировался» на входе: имя и PIN. Забыл PIN — кнопка «PIN» в таблице игроков выдаст новый |
| Всё запуталось, нужно начать заново | «Сбросить игру целиком» в пульте. Бейджи и коды вернутся из папки `pool` — напечатанная стопка останется рабочей |
| Сбросили игру по ошибке | Остановите сервер, найдите в папке `data/` файл `state.json.before-reset-…`, переименуйте его в `state.json` вместо нынешнего и запустите снова |
| Ноутбук перезагрузился | Запустите `start.cmd`, игра продолжится сама. Проверьте адрес в консоли: он мог смениться |

## Перенос игры на другой ноутбук

Проект переносимый, но папка `data/` в репозиторий не входит: на новой машине игра
начнётся с чистого листа и с новым токеном ведущего. Как перевезти начатую игру —
в [network.md](network.md#перенос-на-другой-ноутбук).

## Перед настоящей игрой

Прогоните репетицию с двух-трёх телефонов по чек-листу из
[rehearsal.md](rehearsal.md). Это полчаса, которые снимают почти все сюрпризы.
