# Документация HeadHunter

Документы описывают систему такой, какая она сейчас. Каждый — одна редакция без
наслоений из прежних формулировок: если что-то читается как актуальное, оно актуально.

| Документ | О чём |
| --- | --- |
| [setup.md](setup.md) | Установка и запуск на ноутбуке-сервере, шаг за шагом |
| [game-rules.md](game-rules.md) | Правила игры: контракты, выстрелы, защита, подсказки, очки |
| [architecture.md](architecture.md) | Как устроена система: модули, состояние, сокрытие информации |
| [network.md](network.md) | Локальная сеть, диагностика подключения, перенос игры |
| [rehearsal.md](rehearsal.md) | Репетиция с телефонов: что проверить перед игрой |
| [api.md](api.md) | HTTP API: маршруты игрока и ведущего |
| [history/](history/README.md) | Журнал правок: почему решения такие, какие они есть |

## Чем это отличается от корневого README

Корневой [README.md](../README.md) — короткий вход для того, кто впервые открыл
репозиторий: что за игра и как запустить. Подробности живут здесь.

## Где что искать

Если вы **ведущий и вам нужно провести игру** — читайте [setup.md](setup.md), затем
[game-rules.md](game-rules.md).

Если вы **правите код** — начните с [architecture.md](architecture.md), там же
описано, какой модуль за что отвечает и какие правила нельзя нарушать.

Если вы **не понимаете, почему сделано именно так** — ответ в
[history/](history/README.md). Там же фиксируются новые решения: изменили смысл —
добавьте запись.
