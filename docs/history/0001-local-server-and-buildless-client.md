# 0001. Локальный сервер на ноутбуке и клиент без сборки

- Дата: 2026-08-27 (внесено задним числом)
- Статус: принято

## Контекст

Вечеринка на 30 человек на большой площади. В центре площади можно поставить
ноутбук. У всех участников есть телефоны, но ставить на них приложение никто не
будет. Интернета на площадке может не быть вовсе.

## Решение

Ноутбук — единственный сервер: Node.js и Express. Клиент — веб-страница в обычном
браузере телефона. Фронтенд на ванильных HTML, CSS и JavaScript: ни этапа сборки,
ни внешних CDN.

## Почему

Нативное приложение означало бы установку на тридцать телефонов и возню с двумя
магазинами. Облачный сервер — зависимость от интернета, которого может не быть.
Этап сборки означал бы, что на ноутбуке-хосте нужно уметь собирать фронтенд, а
внешний CDN — что игра ломается вместе с интернетом.

## Последствия

Ноутбук становится единственной точкой отказа: пока он не работает, игра стоит.
Состояние поэтому лежит на диске, а не только в памяти. Доступ идёт по локальному
IP без DNS и без HTTPS — со всеми вытекающими (см. [0004](0004-server-hides-identity-mapping.md)
про то, что это не смертельно для тайны, и раздел про HTTP в
[network.md](../network.md)).
