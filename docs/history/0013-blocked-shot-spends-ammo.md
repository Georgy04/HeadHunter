# 0013. Погашенный щитом выстрел тратит патрон

- Дата: 2026-08-27
- Статус: принято

## Контекст

Щит гасит один выстрел конкретного охотника (см.
[0009](0009-defense-points-and-shield.md)). Оставалось решить, что происходит с
патроном стрелка: патроны приходят раз в час, поэтому цена вопроса высокая.

Расхождение нашлось при переписывании документации: код списывал патрон до
проверки щита, а прежний README обещал, что патрон сохраняется.

## Было / Стало

**Было:** документация обещала, что при погашенном выстреле «патрон и очки не
тратятся». Код при этом патрон списывал всегда — обещание не выполнялось никогда.

**Стало:** патрон сгорает. Очки не меняются, контракт остаётся прежним, по тому же
человеку можно выстрелить снова после кулдауна. Поведение кода не изменилось,
изменилось обещание.

## Почему

Сгоревший патрон — и есть награда защитнику: он потратил попытку защиты, угадал
охотника и за это выключил ему час игры. Если патрон возвращать, щит превращается
в мелкую задержку, а очки за защиту остаются единственной выгодой.

## Последствия

Цена ошибки для охотника выросла: раскрытый охотник теряет патрон, даже опознав
цель верно. Это осознанный перекос в пользу защиты — она сложнее, потому что
охотник о себе не сообщает ничего.
