# 0006. Выстрел по реальному имени вместо выбора эмблемы

- Дата: 2026-08-27 (внесено задним числом)
- Статус: принято

## Контекст

Игрок вычислил, кто скрывается за никнеймом его цели. Нужен способ заявить об этом
в приложении. Рассматривались и физические способы подтверждения: секретный код у
жертвы, QR на бейдже жертвы, подтверждение самой жертвой, подтверждение ведущим.

## Было / Стало

**Было:** игрок стрелял, выбирая эмблему из сетки всех эмблем, показанной в
приложении.

**Стало:** игрок выбирает реальное имя из списка участников — то есть заявляет:
«вот этот человек и есть моя цель». Физические подтверждения отброшены целиком.

## Почему

Сетка эмблем показывала в приложении весь набор эмблем, что противоречит
[0004](0004-server-hides-identity-mapping.md), и позволяла перебирать картинки
вместо разглядывания людей. Выбор имени — ровно то действие, которое игрок
совершает в реальности.

Физические подтверждения отброшены, потому что каждое из них требует, чтобы жертва
или ведущий что-то сделали в нужный момент. На площади с тридцатью людьми это
означает очередь к ведущему и споры.

## Последствия

В API появился `roster` со идентификаторами игроков и их именами. Эмблема нужна
только для узнавания вживую, в интерфейсе выстрела её нет. Понадобилось правило
против перебора: по одному человеку в рамках одного контракта дважды не выстрелить
(`already_tried`), а список попыток обнуляется вместе с контрактом.
