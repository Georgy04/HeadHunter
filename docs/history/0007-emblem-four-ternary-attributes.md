# 0007. Эмблема из четырёх атрибутов по три значения

- Дата: 2026-08-27 (внесено задним числом)
- Статус: принято

## Контекст

Подсказки об эмблеме цели — основной способ продвижения в игре. Владелец
сформулировал требование к их силе: подсказка должна сужать круг примерно втрое,
то есть на тридцати игроках путь выглядит как 30 → 10 → 3-4 → 1.

## Было / Стало

**Было:** набор фигур и цветов был шире и неравномерным, а подсказки делились на
туманные («цвет тёплый», «у фигуры есть углы») и точные. Сколько подозреваемых
отсекает подсказка, зависело от того, какая именно выпала: одна убирала почти
всех, другая почти никого.

**Стало:** ровно четыре атрибута, у каждого ровно три значения — внешняя фигура,
внешний цвет, внутренняя фигура, внутренний цвет. Итого 81 комбинация. Четыре
подсказки на контракт, каждая называет один атрибут точно, порядок случайный.
Набор эмблем раздаётся так, чтобы каждое значение каждого атрибута встречалось
примерно у трети участников.

## Почему

Три значения на атрибут дают требуемое сужение арифметически: каждая подсказка
отсекает две трети. Балансировка раздачи нужна, чтобы это работало не в среднем по
игре, а у каждого игрока: если внешних кругов выпало двадцать пять из тридцати,
подсказка «у цели круг» не сужает ничего.

Палитры внешнего и внутреннего цвета сделаны непересекающимися: иначе подсказка
«цель носит алый» заставляла бы гадать, о каком из двух цветов речь.

## Последствия

Потолок — 81 участник, больше сервер бейджей не выпустит; для большего понадобится
пятый атрибут или четвёртое значение. Формат состояния стал несовместим со старым,
версия поднята, старые сохранения архивируются. Цифры воронки проверяются
автотестом — это единственная гарантия, что балансировка не сломается при правках.
