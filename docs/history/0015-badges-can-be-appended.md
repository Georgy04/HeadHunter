# 0015. Бейджи можно допечатать по ходу игры

- Дата: 2026-08-29
- Статус: принято

## Контекст

Набор бейджей выпускается разом и печатается до игры. Раньше нехватка бейджей
означала неудобство: пришедшему было нечего выдать. После
[0014](0014-server-assigns-emblem-admin-issues.md) стало хуже — без свободного
бейджа регистрация вообще не проходит, потому что резервировать нечего.

## Было / Стало

**Было:** выпуск набора заменял предыдущий и запрещался, если бейджи уже розданы:
«Бейджи уже розданы игрокам. Сбросьте игру, чтобы выпустить новый набор». То есть
добрать бейджи посреди игры было невозможно — только сброс, то есть потеря игры.

**Стало:** появился режим добавления. Он дописывает бейджи к набору, не задевая
выданные и зарезервированные, продолжая тот же троичный счётчик эмблем — повторов
не возникает, баланс атрибутов сохраняется. Лист печати умеет печатать только
невыданные.

## Почему

Сброс игры ради опоздавшего гостя — несоразмерная цена. Замена набора целиком
по-прежнему запрещена, когда бейджи в работе: у людей на руках печатные эмблемы, и
менять их смысла нет.

## Последствия

Ведущему нужно помнить, что после добавления печатать следует только новые бейджи,
иначе он выдаст второй экземпляр уже выданной эмблемы. Для этого есть отдельная
ссылка, но защиты от невнимательности здесь нет.
