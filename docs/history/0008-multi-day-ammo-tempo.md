# 0008. Многодневный темп: пустой магазин, патрон в час

- Дата: 2026-08-27 (внесено задним числом)
- Статус: принято

## Контекст

Игра изначально задумывалась на один вечер, но по ходу обсуждения растянулась на
несколько дней.

## Было / Стало

**Было:** магазин полон на старте, патрон возвращается через минуты — темп на один
вечер.

**Стало:** `ammoStart` 0, `ammoRegenMinutes` 60, `ammoMax` 3,
`shotCooldownSeconds` 120. Формулировка владельца: «сначала без патронов, по
патрону каждый час».

## Почему

Если патроны есть сразу, первый час игры превращается в перебор списка участников:
тридцать имён, десять из них уже дадут попадание случайно. Пустой магазин
заставляет сначала собирать подсказки и разглядывать бейджи. Потолок в три патрона
не даёт накопить залп за сутки простоя и выстрелить веером.

## Последствия

Без подсказок играть невозможно, поэтому активности ведущего становятся
обязательной частью игры, а не украшением: если кодов не выдавать, игра встанет.
Взамен человек может не открывать приложение часами и ничего не терять.
