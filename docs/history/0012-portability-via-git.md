# 0012. Переносимость через git, без привязки к машине

- Дата: 2026-08-27 (внесено задним числом)
- Статус: принято

## Контекст

Разработка идёт на одной машине, а сервером на игре будет другой ноутбук — тот, что
раздаёт сеть. Владелец сформулировал так: проект заливается на git и ставится на
ноутбук, который станет сервером.

## Решение

Репозиторий git; папка `data/` в `.gitignore`; проверка версии Node.js при старте с
понятным сообщением вместо падения на синтаксисе; скрипты запуска `start.cmd` и
`start.sh`, ставящие зависимости при первом запуске; `.gitattributes` с LF для
скриптов и CRLF для `.cmd`; порт через переменную окружения; все локальные адреса и
QR печатаются при старте.

## Почему

Ноутбук-сервер увидят впервые за полчаса до игры, возможно без интернета и без
человека, который помнит, что где лежит. Всё, что можно проверить и подсказать
автоматически, должно проверяться автоматически. Отдельно про переводы строк:
`start.sh` с CRLF на Linux не запускается вообще, и разбираться в этом на площадке
некогда.

## Последствия

На новой машине токен ведущего будет новым: он лежит в `data/`, а та не в
репозитории. Чтобы перевезти начатую игру между машинами, нужно копировать
`data/state.json` руками — автоматической синхронизации нет и не планируется.
