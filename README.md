# HeadHunter

Игра-детектив для большой компании: помесь «Киллера» и социальной дедукции.
Ноутбук работает сервером, игроки заходят с телефонов по локальной сети, интернет
не нужен. Игра рассчитана на несколько дней и не требует, чтобы кто-то сидел в
приложении постоянно.

У каждого участника есть никнейм (тайна), настоящее имя (публично) и бейдж с
эмблемой (на виду, но неизвестно, чей). Приложение выдаёт контракт на никнейм;
задача — по подсказкам вычислить, кто из живых людей за ним стоит, и заявить об
этом раньше, чем вычислят вас.

Игрок регистрируется сам, приложение показывает ему назначенную эмблему, а бейдж
выдаёт ведущий — с этого момента человек в игре. Начало игры тоже за ведущим.

Кроме своего контракта в приложении есть общий сюжет: лидер табло объявляется в
розыск по никнейму, и награду за его голову может забрать любой. Рядом — салун с
разговорами под никнеймами, обезличенная лента событий и блокнот для примет.

Вечер можно разбить на раунды. Каждый следующий раунд перетасовывает никнеймы
между участниками, так что накопленное знание «кто есть кто» перестаёт работать.
Табло при этом начинается с нулей, а сквозной счёт продолжает копиться: его
тратят на аукционе в конце вечера. Табло можно вывести на телевизор — по ходу
игры с никнеймами, а после игры с настоящими именами.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
git clone https://github.com/Georgy04/HeadHunter.git
cd HeadHunter
npm install
npm start
```

На Windows нужен `start.cmd` — двойной щелчок, ничего набирать не надо. Файл
`start.sh` рядом с ним для macOS и Linux, на Windows он не запускается. Остановить
сервер — двойной щелчок по `stop.cmd`.

В консоли появятся адрес для игроков, ссылка на пульт ведущего с токеном, ссылка на
лист бейджей и QR-код для входа. Окно консоли должно оставаться открытым — пока оно
живёт, живёт сервер.

## Что печатать

Бейджи и коды за активности выпущены заранее и лежат в папке `pool` — их печатают
один раз и пользуются весь вечер:

| Файл | Что это |
| --- | --- |
| `pool/badges.html` | 50 бейджей с эмблемами: распечатать, разрезать, раздавать по ходу регистрации |
| `pool/codes.html` | 100 талонов с кодами за активности: подсказка о цели и очки |
| `pool/pool.json` | тот же набор для сервера — он берёт его сам, в том числе после сброса игры |

Открываются двойным щелчком в браузере, печатаются через Ctrl+P. Сброс игры,
переустановка и перенос на другой ноутбук коды не меняют, так что напечатанная
стопка годится всегда. Заново пул выпускают только командой
`node scripts/make-pool.mjs --force` — после неё старую печать надо выбросить.

**Полная инструкция по установке и проведению игры — в [docs/setup.md](docs/setup.md):**
от установки Node.js и правила брандмауэра до выдачи бейджей и старта, с разбором
типовых поломок.

## Проверка

```bash
node scripts/smoke.mjs        # весь игровой сценарий против запущенного сервера
node scripts/check-docs.mjs   # документация не расходится с кодом
```

`smoke.mjs` сбрасывает состояние, поэтому на живой игре его запускать нельзя.
