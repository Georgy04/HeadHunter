# HeadHunter

Игра-детектив для большой компании: помесь «Киллера» и социальной дедукции.
Ноутбук работает сервером, игроки заходят с телефонов по локальной сети, интернет
не нужен. Игра рассчитана на несколько дней и не требует, чтобы кто-то сидел в
приложении постоянно.

У каждого участника есть никнейм (тайна), настоящее имя (публично) и бейдж с
эмблемой (на виду, но неизвестно, чей). Приложение выдаёт контракт на никнейм;
задача — по подсказкам вычислить, кто из живых людей за ним стоит, и заявить об
этом раньше, чем вычислят вас.

Игрок регистрируется сам, приложение показывает ему назначенную эмблему, а бейдж
выдаёт ведущий — с этого момента человек в игре. Начало игры тоже за ведущим.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

На Windows можно просто запустить `start.cmd` двойным щелчком, на macOS и Linux —
`start.sh`: зависимости поставятся сами при первом запуске.

В консоли появятся адрес для игроков, ссылка на пульт ведущего с токеном, ссылка на
лист бейджей и QR-код для входа. Окно консоли должно оставаться открытым — пока оно
живёт, живёт сервер.

**Полная инструкция по установке и проведению игры — в [docs/setup.md](docs/setup.md):**
от установки Node.js и правила брандмауэра до выдачи бейджей и старта, с разбором
типовых поломок.

## Проверка

```bash
node scripts/smoke.mjs       # весь игровой сценарий против запущенного сервера
node scripts/check-docs.mjs  # документация не расходится с кодом
```

`smoke.mjs` сбрасывает состояние, поэтому на живой игре его запускать нельзя.
