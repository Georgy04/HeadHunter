Управление игрой

Сменить раунд — никнеймы перетасуются, табло раунда обнулится, контракты раздадутся заново; сквозной счёт и заметки останутся. Перераздать цели — только новые контракты внутри текущего раунда: никнеймы, очки и салун не трогает, но собранные подсказки по прежним целям пропадут.

Останавливает игру для всех и открывает итоги для аукциона. Нажали случайно — «Продолжить» вернёт раунд как был.

Табло на большой экран: по ходу игры (никнеймы и очки раунда) · итоги вечера (имена и общий счёт — только когда игра закончена).

Бейджи

Набор берётся из папки pool сам — обычно трогать эти кнопки не нужно. «Добавить» допечатывает бейджи сверх пула, не задев уже выданные; «Создать набор» выпускает новые коды, и напечатанная стопка станет бесполезной.

Печать: все бейджи · только невыданные.

Коды за активности

Сотня кодов уже напечатана из папки pool. Здесь выпускают добавочные, если на площадке придумалась новая активность. Печать: все коды · только неотработавшие.
